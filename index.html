使用指南

从注册到上手，整个过程大约五分钟。跟着下面的步骤来就行，遇到卡壳的地方随时找客服聊聊。

1

选择适合的套餐

先看看自己平时主要用来做什么。只是偶尔看看视频，基础版就够用；如果家里几个人同时看剧打游戏，旗舰版会更稳；如果是小团队一起用，团队版的流量和设备数都更宽裕。

2

下载对应平台的客户端

完成订阅后，在用户中心找到对应你设备的客户端下载链接。我们支持主流的桌面和移动平台，下载安装后用订阅链接导入即可。

3

选择节点并连接

打开客户端后，节点列表里会显示当前延迟。日常使用建议选延迟较低的节点；看流媒体时可以切换到对应区域的解锁节点；打游戏时优先选专线节点。

4

遇到问题联系客服

如果连接不上或者速度不理想，别着急。先在用户中心提交工单描述一下你的网络环境，客服会尽快帮你排查。旗舰版和团队版享受优先响应。

客户端信息

轻云兼容主流的代理协议，你可以使用我们推荐的客户端，也可以用自己习惯的第三方工具导入订阅。目前没有独立的官方应用程序，以下是常用兼容方案。

Windows / macOS

推荐使用 Clash Verge 或 v2rayN 导入订阅链接，支持系统代理与 TUN 模式，适合桌面端日常使用。

Android

推荐使用 Clash Meta for Android 或 v2rayNG，从各自官方渠道获取安装包后，导入订阅即可使用。

iOS / iPadOS

App Store 中支持 Shadowrocket 或 Stash 等客户端，导入订阅链接后按需选择节点。

路由器

支持在 OpenWrt 或梅林固件上通过插件导入订阅，适合家庭全屋覆盖场景，需要有一定的网络配置基础。

常见问题

整理了一些大家比较常问的问题，如果这里没有覆盖到你的疑问，可以直接联系客服。

流量用完了会怎样？

当月流量用完后，连接会自动暂停，直到下个计费周期刷新。如果经常不够用，可以考虑升级到更高档位，或者购买额外的流量加油包。

可以试用吗？

目前没有提供免费试用，但所有套餐都支持按月订阅。如果你不确定是否合适，可以先开一个月试试体验，觉得满意再转年付。

支持哪些支付方式？

支持支付宝、微信支付以及部分加密货币。具体可用方式以下单页面显示为准，企业用户如需对公转账可以联系客服单独处理。

年付可以退款吗？

年付套餐在开通后 7 天内、且未使用超过 10GB 流量的情况下支持无条件退款。超出此范围后一般不再受理退款，建议先月付体验。

看 Netflix 会被识别吗？

旗舰版和团队版提供原生 IP 节点，针对主流流媒体做了优化，通常不会被识别为代理网络。基础版解锁能力有限，建议看剧需求强的用户选旗舰版。

多人共享账号会封号吗？

不会封号，但每个套餐有同时在线设备数限制。超出限制时，最早的设备会被自动挤下线。团队版支持 20 台设备同时在线，适合工作室或小公司。
